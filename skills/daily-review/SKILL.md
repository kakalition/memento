# Daily / weekly review

When the owner asks for a review or a digest, work through these steps.

1. **Recap.** Summarize the notes captured this week by theme, not one by one.
2. **Resurface.** Name the pinned notes and anything tagged `task` that is still
   open. Ask which, if any, are now done.
3. **Tidy.** Propose tags for untagged notes and offer to archive finished ones
   (archiving needs approval).
4. **Plan.** Turn the open tasks into a short, ordered list for the coming week.

Keep the whole review to a screenful. Ask before changing notes; suggest rather
than silently reorganizing the owner's knowledge.
